# Meplaniq Logo Package

This package contains the approved **symbol-only Meplaniq MEP logo** with semantic component colors and standard production exports.

## Start here

- [Brand logo system specification](docs/brand_logo_system_spec.md)
- [Primary editable SVG](svg/logo_icon_primary.svg)
- [Primary transparent PNG](png/logo_icon_primary.png)

## Color mapping

- Mechanical / equipment: `#123B7A`
- Electrical / power: `#F4B400`
- Plumbing / water: `#00A6D6`
- AC / HVAC / airflow: `#1F9D55`
- Fixtures / controls accent: `#7C3AED` for UI and technical categories only

## Important production note

The SVG masters are editable vector reconstructions of the approved raster artwork. The original approved raster is retained in `png/logo_icon_approved-raster-1920.png`. For trademark filing, manufacturing, or final legal identity registration, have a designer perform a final manual Bézier/path review.

## Included variants

- Primary color
- Dark-background color
- Monochrome
- Reverse white
- Favicon exports from 16 px to 512 px
- 1024 px transparent PNG exports

A wordmark lockup is not included yet because the exact `meplaniq` wordmark typography has not been approved.
